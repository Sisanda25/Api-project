# Api-project
I was instructed to build a simple REST API using Node.js. The API will handle basic CRUD (Create, Read, Update, Delete) operations for a list of items. where they said i will use the HTTP module to set up the server and the FS module to manage data storage.

# Start the server
npm server.js

# Run tests
npm server.js

2. Get- to retrieve a speicfic user
